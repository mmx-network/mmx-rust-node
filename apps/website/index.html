01 — THE NETWORK

Independent at its core.
Purposeful in its design.

MMX brings together decentralized security, adaptable monetary policy, and a programmable foundation for applications.

PROOF OF SPACE & TIME

A different foundation
for network security.

Farmers commit storage to secure the network, while verifiable time keeps consensus moving. A storage-based approach designed for energy-efficient participation.

01

Supply governed by consensus

Block producers vote on issuance. Transaction-fee burning enables supply contraction, giving the network a dynamic monetary model.

02

Programmable from the start

A high-level virtual machine supports smart contracts and custom tokens, with efficient execution built into Layer 1.
